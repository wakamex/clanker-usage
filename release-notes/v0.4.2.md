Recent agy releases store the account's email instead of its id token, so `agy-usage` named the account after its refresh token and started a new cache file each time the token rotated, leaving the old ones behind. Readers such as the all-accounts table then showed one Antigravity account several times. The account id now comes from the id token, else the email, so it stays the same across rotations. It changes once on upgrade; delete the older files in `~/.cache/clanker-usage/agy/` to drop the duplicates ([`e2768b2`](https://github.com/wakamex/clanker-usage/commit/e2768b252cbce417cbfecc4e572d675546646f2f)).
