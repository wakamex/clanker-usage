This release adds Muse Code, Meta's coding agent, as `muse-code-usage`, and reports Devin's free-model rate limits.

- `muse-code-usage` is new. It shows the Muse Code subscription's 5-hour window and weekly limit, read with the login Muse Code already holds. Muse reports usage only when it signs in and at the end of each model call, so the tool makes the sign-in's key request, which uses no quota and returns the key Muse already stored ([`35df20c`](https://github.com/wakamex/clanker-usage/commit/35df20c3517e4abdb8f5bd245501990a1fad3b92), [`758fec4`](https://github.com/wakamex/clanker-usage/commit/758fec4394847021d7db089a58acec89f47a7ede)).
- `devin-cli-usage` reports the rate limit on Devin's free models, which Devin's status API does not: per model, the last hit, when it resets and whether it still applies, plus the last 50 hits, read from Devin's CLI logs. `status` and `statusline` show a limit that still applies, and `devin-cli-usage configure --log-glob GLOB` adds the logs of other Devin homes ([`42cd088`](https://github.com/wakamex/clanker-usage/commit/42cd08816de677b7e57720cf3766b8f1f37a7192)).
